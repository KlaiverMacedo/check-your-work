# ADR-007 — API Gateway e padrões de integração

**Estado documental:** Decisão documentada; aprovação formal específica a confirmar. **Revisão da consolidação:** pendente de peer-review.  
**Origem:** ADR-007 — Frameworks e Padrões de Integração, pp. 1–2.

## Contexto
SSO, TurnItIn e Mainframe têm contratos distintos e a API precisa de fronteira de segurança.

## Decisão
API Gateway para JWT, rate limiting e reverse proxy; RabbitMQ; Message Translator dentro das ACLs. REST/JSON na borda, SOAP/XML no legado se confirmado. Autorização de recurso continua responsabilidade da aplicação.

## Alternativas consideradas/rejeitadas
Expor a API diretamente; traduzir XML no domínio; integrar sincronamente com todos os sistemas.

## Consequências e trade-offs
Menor acoplamento e política centralizada; latência adicional, risco de SPOF e manutenção de contratos.

## Critérios de validação
Validar JWT, autorização, rate limit e tradução de contrato. Produto de gateway (Kong/NGINX) permanece a definir; não alegar implantação.
