# ADR-010 — API REST/JSON para submissões

**Estado documental:** Proposta de 15/10/2026; ID histórico 003. **Revisão da consolidação:** pendente de peer-review.  
**Origem:** CHECK YOUR WORK.pdf, pp. 2–3.

## Contexto
Cliente necessita confirmação rápida e identificador.

## Decisão
POST /api/v1/submissions sobre HTTPS, HTTP 202 após aceitação durável; OpenAPI versionada e consulta status.

## Alternativas consideradas/rejeitadas
gRPC para cliente web inicial; aguardar avaliação completa na mesma conexão.

## Consequências e trade-offs
Contrato simples; versionamento, autorização e confiabilidade da aceitação.

## Critérios de validação
Teste de contrato, 202 sem esperar avaliação, erros sem publicar trabalho inválido.
